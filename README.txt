VeggieStock Firebase Edition

1. Open this folder in VS Code.
2. Run index.html with Live Server (do not double-click the file).
3. Firestore collection: vegetableItems.
4. Invoice collection: invoiceItems.
5. Inventory Add/Edit/Delete is synced with Firestore.
6. Existing local inventory is migrated to Firestore if vegetableItems is empty.
7. Other devices load inventory from Firestore.
8. Firestore Security Rules must allow the intended reads/writes.
