FIREBASE SETUP
1. Firebase Console -> Authentication -> Sign-in method -> Anonymous -> Enable -> Save.
2. Firebase Console -> Authentication -> Settings -> Authorized domains.
   Add your GitHub Pages domain, for example:
   kulwantsingh637555-cpu.github.io
   Also keep localhost and 127.0.0.1 for local testing.
3. Firebase Console -> Firestore Database -> Rules.
   Publish the included firestore.rules file.
4. Make sure the Web App configuration in firebase.js is the configuration
   generated by Firebase Console -> Project settings -> Your apps -> Web app.
5. Upload the five website/rules files to GitHub Pages using the exact filenames above.

IMPORTANT
- Firestore is the shared inventory source of truth.
- LocalStorage is used as an offline cache / first-time migration.
- Anonymous Authentication must be enabled because the rules require request.auth != null.
- Do NOT make Firestore public read/write.

If the site still shows "API key not valid", the API key itself must be replaced
with the current Web App apiKey from the Firebase Console. That value cannot be
safely guessed or regenerated from the website files alone.
